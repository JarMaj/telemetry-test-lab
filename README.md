# Telemetry Test Lab

A Python-based test automation project for simulating
and validating telemetry communication of a network-connected device.

## Current features

- telemetry generation
- JSON serialization
- UDP telemetry transmission
- UDP telemetry receiver
- pytest-based validation

## Planned

- TCP command interface
- integration tests
- Linux deployment
- SSH-based diagnostics
- failure simulation
- CI/CD
